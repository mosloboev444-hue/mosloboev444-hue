# Привет, я Андрей 👋

**Делаю лёгкие приложения для Android TV — с нуля, без рекламы и лишних зависимостей.**

Лаунчер, IPTV-плеер и VPN-клиент для своей приставки: суммарно меньше **7 МБ** на всё.

### 🔧 Как всё устроено

- **Без AndroidX и сторонних библиотек** — где это возможно.
- **Своя адаптивная вёрстка**: dp-масштаб, колонки и шрифты под экран.
- **Пульт прежде всего**: цифры, MENU, BACK, длинные нажатия.
- **Никакой рекламы, аналитики и аккаунтов.**
- Открытый код, MIT.
