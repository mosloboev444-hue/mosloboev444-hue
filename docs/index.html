Приложения для Android TV

Лаунчер, IPTV-плеер и VPN-клиент. Меньше 7 МБ на всё, без рекламы и аккаунтов.

SlimHome — лаунчер

Стеклянная сетка приложений, погода, кнопка VPN, настройки вида. Работает на Full HD и на старых ТВ через «тюльпаны».

44 КБ · Java · без сторонних библиотек
Скачать APK GitHub

SlimIPTV — плеер

1252 проверенных канала, автообновление плейлиста, цифровой ввод с пульта, пропуск недоступных каналов.

50 КБ · Java · HLS/HTTP
Скачать APK GitHub

SlimVPN — клиент AmneziaWG

Импорт .conf, подключение одной кнопкой и автоматическое включение VPN при запуске YouTube.

6 МБ · Java + Go · обход DPI
Скачать APK GitHub

Лаунчер: до и после

Было — плоские плитки, рамка по контуру, прогноз текстом на 7 дней
Стало — стекло, круглые иконки, анимации, погода чипами, кнопка VPN

Установка по ADB

Подключите приставку по сети или USB и выполните:

adb connect 192.168.0.48:5555
adb install -r SlimHome-2.9.apk
adb shell cmd package set-home-activity --user 0 com.slimhome.launcher/.MainActivity

Как всё устроено

  • Минимум зависимостей — где можно, вообще без AndroidX.
  • Своя адаптивная вёрстка: масштаб, колонки и шрифты пересчитываются под экран.
  • Управление рассчитано на пульт: цифры, MENU, BACK, длинные нажатия.
  • Никакой рекламы, аналитики и аккаунтов. Код открыт, лицензия MIT.
  • Проверено на реальной приставке Tanix W2 (Android 11, Amlogic S905W2).
